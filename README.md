# Zhuoran Xu Personal Website

A static editorial-style academic website for Zhuoran Xu, a first-year PhD student at the School of Physics, Peking University, working on MBE-STM in Prof. Jian Wang's group at ICQM.

## Edit Points

- `index.html`: profile copy, research direction, Scholar link, CV link, and contact details.
- `CV/CV_Zhuoran_Xu.pdf`: undergraduate CV linked from the site.
- `assets/stm-hero.png`: abstract STM-inspired image used in the cover and method sections.
- `styles.css`: Vogue-adjacent editorial layout, typography, colors, and responsive behavior.
- `script.js`: mobile navigation and active section state.

## Preview

Open `index.html` directly in a browser. No build step or local server is required.
