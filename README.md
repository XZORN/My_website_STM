# STM Personal Website

A static academic personal site for a condensed matter physics PhD working with scanning tunneling microscopy.

## Edit Your Information

- `index.html`: replace `Your Name`, email, affiliation, project descriptions, paper titles, and profile links.
- `assets/stm-hero.png`: generated hero image used on the first screen.
- `styles.css`: visual design, spacing, colors, and responsive layout.
- `script.js`: mobile navigation and active section state.

## Preview

Open `index.html` directly in a browser. No build step or local server is required.
